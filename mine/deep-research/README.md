# deep-research

Structured research on a question that matters, ending in a decision rather than a reading list.

## When to use

"Research X", "work out which option to pick", "help me understand this area" — when the answer is
worth several sources and being wrong is expensive.

## How it runs

Clarifying questions first, then explicit success criteria — what would make this research *done*.
Then a multi-agent sweep with web search, findings rated by confidence, a concrete recommendation at
the end, and the artifact saved so the work does not vanish into chat scrollback.

## Not for

Quick factual lookups, debugging, project setup, design work or code review — anywhere the answer is
already obvious.
