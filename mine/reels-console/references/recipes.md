# Рецепты: приёмы монтажа по отдельности

Все команды прогнаны на ffmpeg 8.0.1 (Windows, gyan build) в сентябре 2026.
Ниже — то же самое, что делает `scripts/reel.py`, но по одному приёму за раз:
удобно вставлять в свой конвейер или проверять руками.

Обозначения: `0.51` и `0.25` в примерах — доли кадра, где находятся глаза
(см. рецепт 6). Исходник — вертикальный 4K, 2160×3840.

---

## 1. Смена крупности резким кропом

Кроп берётся от исходника, потом кадр приводится к 1080×1920. Множитель — крупность:
1,0 общий, 1,35 средний, 1,85 крупный.

```bash
ffmpeg -y -i tight.mp4 -vf "crop=trunc(iw/1.85/2)*2:trunc(ih/1.85/2)*2:\
max(0\,min(iw-trunc(iw/1.85/2)*2\,0.51*iw-trunc(iw/1.85/2)*2/2)):\
max(0\,min(ih-trunc(ih/1.85/2)*2\,0.25*ih-trunc(ih/1.85/2)*2/3)),\
scale=1080:1920,setsar=1,format=yuv420p" -c:v libx264 -crf 16 -an shot.mp4
```

Деление на 3 в `y` ставит глаза на верхнюю треть кадра. `trunc(…/2)*2` обязателен:
нечётный размер ломает `yuv420p`.

## 2. Медленный наезд и отъезд

**`crop` для этого не годится.** Его `w` и `h` вычисляются один раз при настройке
фильтра: выражение с `t` внутри них падает с `Error when evaluating the expression`.
Размер во времени меняет только `zoompan`.

```bash
# наезд 100% -> 110% за 3 с (90 кадров)
ffmpeg -y -ss 0 -t 3 -i tight.mp4 -vf \
"zoompan=z='1+0.10*on/89':d=1:x='0.51*iw-(iw/zoom/2)':y='0.25*ih-(ih/zoom/3)':\
s=1080x1920:fps=30,setsar=1,format=yuv420p" -c:v libx264 -crf 16 -an zoom.mp4
```

Отъезд — то же с убывающим `z`. `zoompan` двигает окно целыми пикселями и на мелком
исходнике заметно дрожит; на 2160 точках в ширину при выводе в 1080 шаг гасится вдвое
и дрожания не видно. Ещё один довод снимать в 4K.

## 3. Ударный наезд со смазом движения

Обычное размытие смаз движения не воспроизводит. Настоящий получается так: считаем
движение на 180 кадрах в секунду и усредняем каждые 6 кадров в один.

```bash
ffmpeg -y -ss 6.4 -t 0.2 -i tight.mp4 -vf \
"fps=180,zoompan=z='1.03+(1.5-1.03)*on/35':d=1:x='0.51*iw-(iw/zoom/2)':\
y='0.25*ih-(ih/zoom/3)':s=1080x1920:fps=180,tmix=frames=6,fps=30,\
setsar=1,format=yuv420p" -c:v libx264 -crf 16 -an punch.mp4
```

Ставить 1–2 раза на ролик, на главную мысль.

## 4. Перебивка поверх речи

Перебивка кладётся на готовую видеодорожку, звук остаётся от основного плана.

```bash
ffmpeg -y -i base.mp4 -i broll.mp4 -filter_complex \
"[1:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,\
trim=0:1.8,setpts=PTS-STARTPTS+7.2/TB[b];\
[0:v][b]overlay=enable='between(t,7.2,9.0)'[v]" \
-map "[v]" -map 0:a? -c:v libx264 -crf 16 -c:a copy out.mp4
```

`setpts=…+7.2/TB` сдвигает перебивку на нужную секунду, `enable` открывает её ровно
на её длину.

## 5. Титры: слова с таймкодами и три уровня

Слова с началом и концом даёт whisper:

```bash
ffmpeg -y -i дубль.mp4 -vn -ac 1 -ar 16000 speech.wav
```
```python
import whisper
r = whisper.load_model("small").transcribe("speech.wav", language="ru", word_timestamps=True)
words = [w for seg in r["segments"] for w in seg["words"]]   # у каждого start/end
```

Дальше собирается `.ass` — он умеет то, чего не умеет `drawtext`: стили, поля,
обводку, анимацию появления.

```
Style: Base,Arial,58,&H00FFFFFF,…,2,90,90,300,204
Style: Accent,Arial Black,118,&H00FFFFFF,…,2,60,60,540,204
Style: Cta,Arial Black,132,&H0033E5C6,…,2,60,60,540,204
```

- Цвет в `.ass` пишется задом наперёд: `&H00BBGGRR`. Лаймовый `#C6E533` = `&H0033E5C6`.
- Поп-анимация слова: `{\fscx55\fscy55\t(0,130,\fscx100\fscy100)}` перед текстом.
- `MarginV` 300 у базовых и 540 у акцентных: базовые ниже, акцентные на груди,
  лицо не закрыто и под интерфейс соцсети ничего не уезжает.
- Акцентное слово нужно убрать из базовой строки, иначе покажется дважды.

Прожиг: `-vf "subtitles=subs.ass"`. **Путь только относительный**, а лучше перейти
в папку с файлом: двоеточие диска (`C:\…`) фильтр читает как свой разделитель
параметров и падает.

**Таймкоды живут до первой склейки.** Если паузы вырезаются, времена слов надо
пересчитать по карте «старое время → новое», иначе титры разъезжаются с речью
тем сильнее, чем дальше от начала.

## 6. Привязка кропа к лицу и запас кадра

```python
from insightface.app import FaceAnalysis
app = FaceAnalysis(name="buffalo_l", providers=["CPUExecutionProvider"])
app.prepare(ctx_id=-1, det_size=(640, 640))
f = max(app.get(cv2.resize(img, (w//3, h//3))), key=lambda x: x.bbox[2]-x.bbox[0])
ax, ay = eyes_x / w, eyes_y / h        # доли кадра
```

Искать на уменьшенной втрое картинке: на полном 4K заметно дольше, результат тот же.
Резерв — каскад Хаара из OpenCV, дальше — центр кадра.

Зная рамку лица, можно посчитать **предельную крупность**: ту, после которой кроп
срезает макушку. Если она около 1,0 — дубль снят слишком близко, и смены крупности
в ролике не будет. Это стоит сказать человеку до монтажа, а не после.

## 7. Звук: музыка под голосом, приглушение, эффекты

```bash
ffmpeg -y -i video.mp4 -i music.wav -i voice.mp4 -i whoosh.wav -filter_complex \
"[2:a]aformat=fltp:44100:stereo,asplit=2[sc][voice];\
[1:a]aformat=fltp:44100:stereo,volume=0.25[m];\
[m][sc]sidechaincompress=threshold=0.02:ratio=10:attack=15:release=350[mduck];\
[3:a]aformat=fltp:44100:stereo,adelay=4900|4900,volume=0.45[s];\
[voice][mduck][s]amix=inputs=3:duration=first:normalize=0,alimiter=limit=0.95[a]" \
-map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k out.mp4
```

Замер на этой цепочке: музыка под речью −47 дБ, в паузах −33 дБ. То есть она сама
проваливается на 14 дБ и сама возвращается.

- `normalize=0` у `amix` обязателен: иначе он делит громкость на число входов,
  и чем больше звуков в ролике, тем тише голос.
- `asplit` нужен только чтобы отдать голос в боковую цепь компрессора. Если музыки
  нет, второй выход останется висеть и ffmpeg откажется собирать граф.
- `alimiter` в конце ловит перегруз на стыках.

## 8. Вырезание пауз

```bash
ffmpeg -v info -i speech.wav -af "silencedetect=noise=-32dB:d=0.45" -f null -
```

Из лога берутся пары `silence_start` / `silence_end`. От каждой паузы стоит оставить
0,15–0,2 секунды, иначе речь звучит рублено. Остальное вырезается через
`trim` + `atrim` + `concat`. На живом дубле: 52,7 с → 40,0 с, 21 пауза.

### 10. Ролик в рамке

Окно 1030×1288 (4:5) по центру холста 1080×1920, скругление 50 px, фон чёрный.
Маска делается один раз одной картинкой: чёрное всё, кроме скруглённого окна.

```bash
ffmpeg -f lavfi -i color=c=black:s=1080x1920:d=1 -vf "format=rgba,geq=r=0:g=0:b=0:\
a='255*(1-between(X,25,1054)*between(Y,316,1603)*lte(pow(max(0,max(75-X,X-1004)),2)\
+pow(max(0,max(366-Y,Y-1553)),2),2500))'" -frames:v 1 mask.png
# ролик: scale=1030:1288,pad=1080:1920:25:316:black, потом overlay маски
```

Дубль заранее режется под пропорции окна (глаза на 35% высоты), и планы рендерятся
сразу в 1030×1288 — иначе кроп 9:16 пришлось бы ещё раз резать, и лицо уехало бы
на каждой смене крупности. Титры в рамке поднимаются: `MarginV` 400 и 620 вместо 300 и 540.

### 11. LUT с силой смешивания

```bash
-filter_complex "[0:v]split[a][b];[b]lut3d=file=look.cube[l];[a][l]blend=all_expr='A+(B-A)*0.5'"
```

`lut3d` сам силы не имеет — смешивается с исходником через `blend`. Путь к `.cube` с
двоеточием диска фильтр ломает так же, как `subtitles`: файл копируется в рабочую папку.

### 12. Засвет на склейке

Тёплое пятно из угла, прозрачное к краям, — одна картинка через `geq`, дальше
показывается на 0,33 с: 0,1 с нарастает, 0,21 с гаснет.

```bash
geq=r=255:g=205:b=150:a='255*pow(max(0,1-hypot(X-W*0.85,Y-H*0.2)/(W*1.3)),1.6)'
# [flash]fade=in:st=0:d=0.1:alpha=1,fade=out:st=0.12:d=0.21:alpha=1,setpts=PTS-STARTPTS+T/TB
# [v][flash]overlay=enable='between(t,T,T+0.33)':eof_action=pass
```

Проверено 2026-09-23 на живом дубле: рамка, LUT, два засвета и перебивка с замедлением 0,85
собираются одним проходом, 40 секунд ролика — около двух минут на ноутбуке.

### 13. Громкость к стандарту соцсетей

Без этого шага ролики выходили около −27 LUFS, вдвое тише соседних в ленте.
Цель −14 LUFS, пик не выше −1 дБ. Один проход `loudnorm` промахивается мимо цели,
поэтому два: первый меряет, второй ставит по замеру.

```bash
ffmpeg -i mixed.mp4 -af "highpass=f=80,loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json" -f null -
# из JSON берутся input_i, input_tp, input_lra, input_thresh, target_offset
ffmpeg -i mixed.mp4 -af "highpass=f=80,loudnorm=I=-14:TP=-1.5:LRA=11:measured_I=…:measured_TP=…:\
measured_LRA=…:measured_thresh=…:offset=…:linear=true,aresample=48000" -c:v copy -c:a aac -b:a 256k out.mp4
ffmpeg -nostats -i out.mp4 -af ebur128=peak=true -f null -    # приёмка: I и Peak из Summary
```

Потолок пика в фильтре −1,5, а не −1: кодек AAC добавляет около 0,5 дБ сверху.
Проверено на живом дубле: −27,1 → −14,7 LUFS, пик −1,3.

### 14. Переслушать подозрительные места расшифровки

Слово длиннее секунды (норма 0,2–0,7 с) значит, что распознавание склеило или потеряло
кусок. Такой кусок до 5 с вырезается от паузы до паузы и расшифровывается отдельно,
без контекста всего ролика (`condition_on_previous_text=False`). Замена принимается,
если слов стало больше или самое длинное слово стало короче.

Три вещи, без которых переслушивание портит текст, а не чинит:
- резать кусок только по паузе. На обрыве посреди слова whisper дописывает выдумку («что тебе по…»);
- написание и знаки брать из полной расшифровки, а не из обрывка: на обрывке окончания
  хуже («насыщенной продуктивной» вместо «насыщенный, продуктивный»);
- слово, которое раньше стояло не на своём месте, после переслушивания появляется заново,
  а старая копия остаётся в 3 секундах рядом. Её надо убрать, иначе в титрах слово дважды.

### 15. Слово в вырезанной паузе

Whisper ставит короткое слово («я», «и», «мне») на 0,2–0,6 с раньше, чем оно звучит,
то есть в паузу перед ним. После вырезания паузы начало и конец слова схлопываются в одну
точку, и слово молча пропадает из титров. Лечится сдвигом: слово, чья середина попала
в вырезанный кусок, переносится в ближайший оставленный (`snap_words`).

### 16. Проверка склеек по звуку

Огибающая громкости окнами по 10 мс, порог речи = min(−30 дБ, уровень речи p95 − 20 дБ).
- В 0,3 с за краем склейки 15 и больше громких окон, и ближайшее не дальше 80 мс:
  край попал внутрь слова.
- В вырезанной паузе звук чуть ниже порога дольше 80 мс: возможно тихий слог или вздох.
- Кусок, где звук есть, а слов в расшифровке нет: вздох, оговорка или потерянная фраза.
  На живом дубле так нашёлся вздох «а-а…» на 38-й секунде; убирается `--drop 37.8-39.0`.

На каждой склейке звук затухает и нарастает за 15 мс (`afade`), иначе стык щёлкает.

### 17. Титры плашкой

Стиль `.ass` с `BorderStyle=3`: вместо обводки текст получает сплошную подложку,
её цвет берётся из `OutlineColour`, а `Outline` становится полем вокруг текста.

```
Style: Plate,Arial,60,&H00141010,&H0033E5C6,&H0033E5C6,-1,0,0,0,100,100,0,0,3,14,0,7,70,60,1440,204
```

Фраза до 26 знаков; на каждое слово своё событие с текстом «все слова до этого включительно»,
от начала слова до начала следующего. Выравнивание 7 (левый верх): плашка растёт вправо
и не дёргается. Высота считается от замера лица: 95-й процентиль низа лица по ролику + 44 px,
но не выше 1250 и не ниже 1440.

### 18. Обложка нулевым кадром и миниатюрой

Мессенджеры показывают нулевой кадр, проводник показывает вшитую миниатюру.
Кадр заменяется, а не добавляется: длина и синхрон звука остаются прежними.

```bash
# замена кадра 0 в том же проходе, где прожигаются титры
-filter_complex "[0:v]subtitles=subs.ass[s];[1:v]scale=1080:1920[c];[s][c]overlay=enable='eq(n,0)'"
# миниатюра файла, без перекодирования видео
ffmpeg -i reel.mp4 -i cover.jpg -map 0:v:0 -map 0:a:0 -map 1:v:0 -disposition:v:1 attached_pic -c:v copy …
```

После этого в файле два видеопотока. Всё, что читает ролик дальше (раскадровка, замеры),
должно брать `-map 0:v:0`, иначе ffmpeg может выбрать обложку.

Кандидаты на обложку берутся на стыках вырезанных пауз: там человек молчит. Глаза и рот
скрипт не видит, поэтому лист кандидатов `cover-sheet.png` надо смотреть глазами.

## Грабли

- **Поворот у видео с телефона.** `ffprobe` показывает размер как он лежит в файле,
  а декодер отдаёт уже повёрнутый кадр: запись 3840×2160 с меткой поворота приходит
  как 2160×3840. Размеры в фильтрах писать выражениями `iw`/`ih`, а не числами,
  и проверять `stream_side_data=rotation`.
- **`crop` не умеет менять размер во времени** (рецепт 2). Только `zoompan`.
- **`subtitles=` и путь с двоеточием** (рецепт 5).
- **Планы, отрендеренные с `-an`, теряют звук.** После `concat` дорожки нет вообще,
  звук подмешивается в самом конце из файла до нарезки.
- **`amix` без `normalize=0`** тихо съедает громкость голоса.
- **Запас на приближение считается от вертикали.** Вертикальный 4K — приближение
  до 2,0×. Горизонтальный 4K, из которого вырезали вертикаль, — уже 1,12×.

### Грабли из чужого опыта

Взято из списка граблей плагина `it-reelsmaker` (github.com/itpartypattaya/reels-montage, MIT),
который собран на реальных роликах. Здесь то, чего у нас ещё не было; своими руками проверено
только помеченное «наше».

Резка и речь:
- **«Видео прыгает назад».** Это пропущенный повторный дубль: whisper склеил повтор фразы
  в одно растянутое слово. Искать не сбой рендера, а слово длиннее секунды в ±2 с от этого места.
  Расшифровка готового ролика целиком повторов не видит в принципе.
- **Слово слышно дважды после склейки, а по тексту всё чисто.** Край попал в провал 30–60 мс
  внутри слова, whisper отдал хвост слова следующему. Ловится только проверкой по звуку (рецепт 16).
- **Край склейки ставить в самую длинную тишину между словами**, а не в первый провал,
  и не двигать его под таймкоды whisper: они гуляют на 0,2–0,6 с. (наше: видели сдвиг до 1 с)
- **Пауза короче 150 мс не режется.** Безударный слог такой длины от паузы не отличить:
  «пока вы спите» превращается в «ка вы спите».
- **Шум фона −38 дБ и громче** (улица, кондиционер) детектор принимает за речь.
  Сверять с расшифровкой: где «речь» есть, а слов нет.
- **Исходник уже ускорен автором в телефоне.** Темп выше примерно 9 слогов в секунду
  значит, что своё ускорение ставить нельзя: речь станет суетливой. Слоги считаются
  как гласные в расшифровке, делённые на время речи без пауз.
- **Какой дубль брать:** по умолчанию последний; если человек вслух одобрил себя
  («вот так хорошо»), то предыдущий; целая фраза лучше оборванной, даже точнее сформулированной.

Цвет и звук:
- **После LUT картинка жёлтая.** LUT сам сдвигает баланс. Правка баланса ставится до LUT,
  а меряется по результату после него, на серых и белых предметах, не на коже.
- **Кадр с цветным светом** (небо в окне, неон, оранжевая стена) автоматический баланс
  ломает. Брать пипеткой известный белый предмет: футболку, стену, лист. (наше: на оранжевой
  стене и жёлтой футболке замер честно отказался)
- **Шумоподавление только если шум громче −50 дБ.** На чистой записи оно даёт артефакты.
- **Ролик без голоса выходит короче плана**, если картинку и звук склеивали с `-shortest`,
  а звуковая дорожка кончилась раньше. Звук дотягивать тишиной до конца.

Титры и кадр:
- **Титры нечитаемы на белой рубашке или стене.** Затемнения 15–25% мало, нужно 42–60%
  или подложка. Обводка и свечение выглядят устаревшими.
- **Ложные «лица»** детектор находит на коленях, сложенных руках и складках одежды,
  чаще всего как раз в зоне титров. Отсеивать по уверенности и форме.
- **Мастер собрался из старого рендера.** Рендер шёл через `| tail` в одной цепочке
  с мастерингом, `tail` спрятал падение. Рендер запускать отдельной командой и смотреть
  код выхода и время файла.

Если ролик рендерится через Remotion:
- **«No frame found at position N».** Первая причина: видео в файле начинается не с нуля,
  потому что куски с AAC-звуком склеивали одним `concat`. Клеить видео и звук раздельно,
  проверять `start_time` = 0 у обоих. Вторая причина, если N каждый раз разный: Remotion
  считает кэш видео от свободной памяти на старте. Лечится
  `Config.setOffthreadVideoCacheSizeInBytes(384 * 1024 * 1024)` в `remotion.config.ts`.
- **Горизонтальное видео сжалось в узкую полосу.** Tailwind ставит `video { max-width: 100% }`.
  На видео нужен `maxWidth: "none"`.
- **Строки вылезают за кадр, хотя ширину мерили.** Текст измерили до загрузки шрифта,
  по ширинам запасного. Мерить только после загрузки.
- **На обложке текст из шаблона, а не из ролика.** `--props` накладываются поверх
  `defaultProps`, непустое значение по умолчанию побеждает. Держать там `null`.
- **Элемент, привязанный к слову, появился раньше слова.** Код нашёл более раннее
  вхождение того же слова. Искать слово только в окне самого элемента.
- **Поздняя точечная правка** (слово в титре, позиция плашки) не требует полного рендера:
  перерисовать кусок между соседними ключевыми кадрами и вклеить. Минута ролика: 8–10 мин
  полностью против 40–50 с куском.
