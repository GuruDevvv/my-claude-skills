# human-text

Russian-language copy that reads as written by a person, not generated by one.

## When to use

Anything meant for humans to read: Telegram posts, articles, landing copy, letters, newsletters,
announcements, product descriptions, video scripts. Also for rewriting — "make this sound alive",
"it reads like a language model", "cut the filler".

## What it does

Varies sentence rhythm (uniform length is the loudest tell), allows honest hedging instead of
confident mush, and strips the specific clichés that mark machine text in Russian — including the
twin-antithesis construction that AI reaches for whenever it wants to sound profound.

## Not for

Code, commit messages, technical documentation, handoffs, internal reports — or English copy: the
rules are tuned to Russian.

---

🇷🇺 Правила живого русского текста: неровный ритм, честные оговорки, без клише вроде «это не X,
а Y». Не для кода, документации и английского.
